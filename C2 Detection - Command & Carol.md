# C2 Detection - Command & Carol

This room talks about RITA - Real Intelligence Threat Analytics. It focuses on convert PCAP to Zeek logs, Use RITA to analyse Zeek logs and analyse the output of RITA.

Real Intelligence Threat Analytics (RITA) is an open-source framework created by Active Countermeasures. Its core functionality is to detect command and control (C2) communication by analyzing network traffic captures and logs. Its primary features are includes but not limited to C2 beacon detection, DNS tunnelling detection, Long connection detection, Data exfiltration.

RITA runs several analysis modules collecting information like periodic connection intervals, excessive number of DNS queries, long FQDN, random subdomain etc…

RITA only accepts network traffic input as Zeek logs. Zeek is an open-source network security monitoring (NSM) tool.
