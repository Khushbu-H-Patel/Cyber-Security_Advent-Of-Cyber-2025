# ICS/Modbus - Claus for Concern

This room talks about the SCADA (Supervisory Control and Data Acquisition and how it is used to monitor industrial processes, PLC (Programmable Logic Controllers) to perform the automation, Modbus protocol and how it is used to enable the communication between industrial devices.

SCADA: SCADA acts as the bridge between human operators and the machines doing the work. It senses what's happening, processes that information, and sends commands to make things happen.
Components of SCADA: Sensors and actuators, PLCs, Monitoring systems, Historians

PLC: A PLC (Programmable Logic Controller) is an industrial computer designed to control machinery and processes in real-world environments. PLCs are designed to survive harsh environments, run continuously without failure, and execute control logic in real-time, interface directly with physical hardware. 

Modbus: Modbus is the communication protocol that industrial devices use to talk to each other. It's one of the oldest and most widely deployed industrial protocols in the world.
